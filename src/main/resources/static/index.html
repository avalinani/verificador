Firmar un documento PDF

Firma electrónicamente un PDF con tu propio certificado (DNIe, FNMT, ...) usando AutoFirma, la aplicación oficial de firma de escritorio. Solo funciona en equipos de sobremesa con AutoFirma instalado.

La clave privada de tu certificado nunca sale de tu equipo: AutoFirma firma el documento localmente y este servicio no recibe el PDF sin firmar en ningún momento de este proceso. El PDF firmado solo llega al servidor si tú decides pulsar «Validar este PDF» a continuación. ¿No tienes AutoFirma? Descárgala aquí.
